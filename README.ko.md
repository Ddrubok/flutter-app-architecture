# Flutter 앱 구조 설계

[English](README.md)

Flutter 앱에서 사용자의 동작이 화면에서 시작해 데이터 저장까지 어떻게 이어지는지 설계합니다.

```text
$flutter-app-architecture 습관 기록 앱에서 사용자가 저장을 누르자마자 화면을 닫아. 저장 중인 작업은 누가 맡고, 돌아왔을 때 목록에 어떤 결과가 보여야 하는지 설계해줘.
```

## 설치

[스킬 ZIP 다운로드](https://github.com/Ddrubok/flutter-app-architecture/releases/latest/download/flutter-app-architecture.zip) 후 Codex 스킬 폴더에 압축을 풉니다. 기본 위치는 `~/.codex/skills`이고, `CODEX_HOME`을 설정했다면 `$CODEX_HOME/skills`입니다. 압축 파일 안에 이미 `flutter-app-architecture` 폴더가 들어 있습니다. 설치 후 `flutter-app-architecture/SKILL.md`에서 지침을 확인할 수 있습니다.

이 스킬은 단독으로 쓸 수 있습니다. 범용 스킬을 사용 중이라면 설계 도중 필요한 시점에 이 스킬을 받습니다. [범용 소프트웨어 구조 설계](https://github.com/Ddrubok/software-architecture)
